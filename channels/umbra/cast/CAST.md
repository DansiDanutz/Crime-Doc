# umbra. — Channel cast (signature recurring ensemble)

Six named figures, four roles. Same mannequin DNA every time (eggshell featureless heads,
locked color code, white-void references), but each character has a **signature silhouette**
so the channel's cast is recognizable across episodes. Generate each once, save as a
Reference Element, then re-skin only the wardrobe per story.

All obey the locked DNA color code (`dna/CHANNEL_DNA.md` §8):

| Role | Character | Color treatment |
|------|-----------|-----------------|
| **MAIN SUBJECT** | **Vesper** | matte **RED** |
| **SECONDARY SUBJECT** | **The Insider** | glossy **WHITE** + one photoreal signifier |
| **SECONDARY SUBJECT** | **The Courier** | glossy **WHITE** + one photoreal signifier |
| **POLICE** | **The Detective** | matte **BLACK** |
| **SPECIAL POLICE** (solver) | **The Breacher** | matte **BLACK** + photoreal tactical gear |
| **SPECIAL POLICE** (solver) | **The Marksman** | matte **BLACK** + photoreal tactical gear |

> Red is reserved for the **single** main subject. Secondaries stay white but each carries
> **one** photoreal item so the audience tells them apart without facial features. Police are
> black; the special-police "solvers" get photoreal tactical gear because the kit carries the
> information (who ends it).

## Lock rules
- **One** red MAIN SUBJECT per episode — red is never given to a secondary or police figure.
- Secondary subjects: white body + exactly one photoreal signifier item (their identifier).
- Police / special police never become red and never get facial features.
- Weapons are slung, holstered, or implied by stance — never aimed at a figure, never firing
  (DNA: violence by composition only, never graphic).
- Generate each figure once → save as a Reference Element → reuse everywhere (CHARACTER LOCK).

## Per-episode re-skinning
In each episode's `03-characters.md`, copy the figures you need and swap only the wardrobe to
fit the story (Vesper's trench → a hacker's hoodie or a pilot's jacket; The Breacher's POLICE
plate → FBI / customs / military). Keep the color treatment and signature prop identical so the
character stays recognizable.
