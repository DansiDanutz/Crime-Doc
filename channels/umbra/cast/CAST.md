# umbra. — Channel cast archetypes

Reusable roles, re-skinned per episode with episode-specific wardrobe. Per-episode
character prompts live in each episode's `03-characters.md`; this file is the pattern they
follow so the channel stays visually consistent.

## THE ONE — matte red protagonist
The single human in collision with the system. Always **matte red** mannequin, eggshell
head, realistic proportions. Wardrobe is suggested (silhouette of a uniform/coat) but kept
red so the figure reads as the protagonist first. Isolated framing.

## THE SYSTEM — matte black institution
The agency/military/police/network. **Matte black** mannequins, identical and
interchangeable, usually in numbers, flanking or surrounding THE ONE. Faceless by design.

## THE SUITS — black body + photoreal authority uniform
When rank/authority is the point (a general, a director, a judge), layer a photoreal dress
uniform over the black body so the uniform carries the information.

## THE WORLD — glossy white civilians
Crowds, sleepers, families, commuters. **Glossy white** mannequins. The stakes. Often shown
unaware, in Mode B environments, to contrast with the red figure's burden.

## Lock rules
- One red figure per episode unless the story genuinely has two protagonists.
- Black figures never get facial features and never become red.
- Generate each figure once → save as a Reference Element → reuse everywhere (CHARACTER LOCK).
