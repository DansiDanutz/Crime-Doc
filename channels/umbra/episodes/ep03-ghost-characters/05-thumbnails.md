# STATE 6 — Thumbnail prompts (5 variants)

> Red Hacker, black institution (Bundespost/bank), white public. Stark contrast, label tags +
> triangular pointers, minimal bold text. Emotion: exposure / the false promise. Generate in
> Nano Banana Pro, `count: 4` each.

## Variant 1 — "Ghost Characters"
- **Concept:** red hacker at a CRT where a bank's password is bleeding through the screen as garbled overflow characters.
- **Text overlay:** RED tag "OVERFLOW" (at the screen) · BLACK tag "PASSWORD" (at the leaked line)
- **Emotion trigger:** the secret thing appearing where it never should.
- **Composition note:** red figure lower-left in profile, huge CRT filling upper-right, one line of the garble glowing brighter than the rest.
- **Prompt:**
```
Cinematic photorealistic 3D render thumbnail, a matte red featureless mannequin (eggshell head,
1980s cardigan) in profile lower-left before a large boxy CRT monitor that fills the upper-right,
the screen dense with blocky videotex characters spilling into garble, one leaked login line
glowing brighter, dim 1980s room, stark high-contrast lighting, key from above, deep shadows,
bold red / pure white / deep black palette with cool CRT-green glow, shallow depth of field,
volumetric light, cinematic color grade, Unreal Engine 5, octane render, 8K, anamorphic lens,
shot on ARRI Alexa, 16:9. Overlaid graphic tags: a RED rectangular tag reading "OVERFLOW" with a
triangular pointer at the screen; a BLACK rectangular tag reading "PASSWORD" with a triangular
pointer at the glowing leaked line. Bold ALL-CAPS sans-serif, white text.
```
