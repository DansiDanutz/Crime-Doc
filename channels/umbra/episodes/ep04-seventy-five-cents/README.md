# Episode template

Clone this folder to start a new episode (use `tools/new-episode.sh <channel> <slug>`).

Fill the files in workflow order:
1. `episode.yaml` — metadata
2. `01-idea.md` — STATE 2
3. `02-script.md` — STATE 3
4. `03-characters.md` — STATE 4
5. `04-scenes.md` — STATE 5  (then mirror into `production/shotlist.json`)
6. `05-thumbnails.md` — STATE 6

Keep everything conformant to `dna/CHANNEL_DNA.md`. Production calls live in
`docs/PRODUCTION_PIPELINE.md`. See the worked reference at
`channels/umbra/episodes/ep01-the-man-who-said-no/`.
